使用说明

这是浏览器单文件视觉原型，包含页面切换、主题切换、三维观察、 演示圆盘、日期操作和本机设置保存。它没有导入原 Swift 项目的计算服务， 因此星体经度和宫位不能作为正式排盘结果。

GitHub 尚未部署：当前 GitHub 连接器未连接。 请到设置中的 Connectors 页面连接 GitHub，再指定要部署的仓库。
